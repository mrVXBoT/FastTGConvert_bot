## 1. परियोजना अवलोकन

FastTGConvert एक Python आधारित (Aiogram 3.x, Telethon, SQLAlchemy 2.0) एसिंक्रोनस टेलीग्राम बोट है जो टेलीग्राम सेशन फ़ाइलों के सुरक्षित रूपांतरण और प्रबंधन के लिए डिज़ाइन किया गया है।

### मुख्य विशेषताएं
- **सेशन रूपांतरण**: `.session` ↔ `TData` (Telegram Desktop zip), `.json` और `.txt` में द्विदिश रूपांतरण।
- **सुरक्षा उपकरण**: 2FA पासवर्ड परिवर्तन/रीसेट, @SpamBot प्रतिबंध जांच, चैट क्लीनर, संपर्क हटाएं।
- **एडमिन पैनल**: RBAC (OWNER, SUPER_ADMIN, ADMIN, SUPPORT) भूमिकाओं के साथ इनलाइन कीबोर्ड एडमिन पैनल।

## 2. त्वरित स्थापना

```bash
git clone https://github.com/mrVXBoT/FastTGConvert_bot.git
cd FastTGConvert_bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python3 -m app
```
