## ১. প্রকল্পের বিবরণ

FastTGConvert হল Python (Aiogram 3.x, Telethon, SQLAlchemy 2.0) দ্বারা তৈরি একটি অ্যাসিনক্রোনাস টেলিগ্রাম সেশন ব্যবস্থাপনা সিস্টেম।

### মূল সুবিধাসমূহ
- **সেশন কনভার্সন**: `.session` ↔ `TData` (Telegram Desktop zip), `.json` এবং `.txt` দ্বিমুখী পরিবর্তন।
- **সিকিউরিটি টুলস**: 2FA পাসওয়ার্ড পরিবর্তন/রিসেট, @SpamBot অ্যাকাউন্ট লিমিট পরীক্ষা, চ্যাট ক্লিনার, পরিচিতি ডিলিট।
- **এডমিন প্যানেল**: Inline Keyboard ভিত্তিক RBAC সুবিধা (OWNER, SUPER_ADMIN, ADMIN, SUPPORT)।

## ২. দ্রুত ইনস্টলেশন

```bash
git clone https://github.com/mrVXBoT/FastTGConvert_bot.git
cd FastTGConvert_bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python3 -m app
```
