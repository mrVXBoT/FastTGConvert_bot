## 1. نظرة عامة على المشروع

منظومة FastTGConvert مصممة خصيصاً لتحويل وتدقيق جلسات التليجرام بشكل آمن وسريع باستخدام Aiogram 3.x و Telethon و SQLAlchemy 2.0.

---

## 2. ميزات النظام الرئيسية

- **تحويل صيغ الجلسات**: تحويل متبادل بين `.session` و `TData` (Telegram Desktop) بالإضافة إلى تصدير صيغ `.json` و `.txt`.
- **أدوات الحسابات**: فحص عمر الحساب، فحص القيود عبر @SpamBot، إدارة التحقق بخطوتين (2FA)، وتغيير الإعدادات والخصوصية.
- **لوحة تحكم المشرفين**: لوحة تفاعلية بالكامل تعتمد على المفاتيح المضمنة (Inline Keyboards) مع دعم الصلاحيات المتقدمة (RBAC).

---

## 3. التشغيل السريع

```bash
git clone https://github.com/mrVXBoT/FastTGConvert_bot.git
cd FastTGConvert_bot
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python3 -m app
```
